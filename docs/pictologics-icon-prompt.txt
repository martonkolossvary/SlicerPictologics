Use case: logo-brand.
Asset type: production icon for the Pictologics radiomics extension in 3D Slicer, square PNG master, to be reduced to 256, 128, 64 and 32 pixels.

All elements fully inside the canvas, balanced margins.
Constraints: recognizable strong cube silhouette at 32 pixels, generous dark gaps and large color fields, no lettering whatsoever, no Pictologics wordmark, no initials, no numbers, no Slicer logo, no medical cross, no endorsement badges, no watermarks, no border ornamentation, no decorative particles. Return only one icon, no contact sheet or mockup. Prefer a 1024 by 1024 square master.
